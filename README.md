Image Deepfake Detection
This project is a web-based application designed to identify and detect deepfake or manipulated images using machine learning. It features a modern web interface for users to upload images and receive real-time analysis results.
A simple web application to detect whether an image is Real or Fake using machine learning.

Features
Easy Upload: Drag and drop images to analyze.

Fast Results: Real-time deepfake classification.

Clean UI: Simple and intuitive web interface.

📁 Project Structure
backend/: Flask server for handling image processing.

training/: Scripts for model training and datasets.

static files: Frontend (index.html, style.css, script.js).

🛠️ How to Run
Install dependencies:

Bash
pip install -r requirements.txt
Start the backend:

Bash
python backend/app.py
Open the App:
Simply open index.html in your browser.

🧠 Tech Stack
Frontend: HTML, CSS, JavaScript

Backend: Python (Flask)

AI: TensorFlow / Keras / OpenCV
